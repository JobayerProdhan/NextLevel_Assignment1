# TypeScript Problem Solving & OOP Assignment

## Overview

This assignment focuses on practicing TypeScript fundamentals and Object-Oriented Programming (OOP) through 8 problem-solving tasks and 2 technical blog posts.

## Topics Covered

- Basic Types & Function Parameters
- Union Types & Type Narrowing
- Readonly Tuples
- Interfaces & Generics
- `keyof` and Indexed Access Types
- Classes, Inheritance & Access Modifiers
- Promises & Async/Await
- Type Aliases vs. Interfaces
- `any`, `unknown` & `never`

## Learning Outcomes

By completing this assignment, I practiced and strengthened my understanding of:

1. **TypeScript Fundamentals:** Using basic types, optional parameters, default values, and rest parameters.
2. **Type Safety:** Applying union types and type narrowing using `typeof`.
3. **Tuples:** Working with readonly tuples to represent structured data.
4. **Generics:** Building reusable and type-safe functions.
5. **Interfaces:** Defining object structures and implementing data filtering.
6. **Advanced Types:** Understanding `keyof` and indexed access types.
7. **Object-Oriented Programming:** Implementing classes, inheritance, encapsulation, and access modifiers.
8. **Asynchronous Programming:** Handling Promises, async/await, and error handling.
9. **Type System:** Understanding type aliases, interfaces, `any`, `unknown`, and `never`.

## Learning Goals

To improve problem-solving skills, strengthen my understanding of TypeScript, and develop the ability to write clean, reusable, maintainable, and type-safe code.
